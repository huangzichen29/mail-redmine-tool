# 邮件 ↔ Redmine转记工具 2.3.1

Chromium 侧边栏扩展，支持中文、日语、英语。扩展只会把内容填写到 Redmine 草稿中，不会提交票据。

## 下载与安装

1. 下载并解压“邮件Redmine_2.3.1.zip”。
2. 在 Edge 地址栏打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”，选择 `邮件Redmine_2.3.1` 文件夹。
4. 刷新 Outlook 和 Redmine 页面，点击工具栏扩展图标打开侧边栏。

2.3.1 使用独立文件夹，可先在扩展管理页移除旧版后再加载；模板和字段偏好存储在浏览器扩展本地，升级前可在齿轮设置中导出模板配置。

## 邮件票

1. 在 Outlook 网页版打开邮件，在“邮件转记”标签页点击“提取当前邮件”。对话邮件会尝试配对每封邮件的时间和正文，正文按最新邮件在前、较早回复在后的顺序合并；详细格式可在模板配置中调整。
2. 检查或编辑标题、收件时间、正文和 Redmine 説明预览。
3. 打开 Redmine 新建票页面，按需填写邮件票标签页独立的担当者、対応目途天数、重要度和ウォッチャー，然后选择转写外部票或内部票。
4. 检查 Redmine 页面后手动提交。内部票題名会追加“（外部#票号）”。

## コールセンターチケット

1. 在“コールセンター”标签页，先打开外部 Redmine 的目标 `/issues/票号` 页面，再点“读取当前外部票”。工具会提取票号、标题、说明、优先度和当前页面链接；内容可编辑。
2. 切换到内部 Redmine 的新建票页面，确认コールセンター标签页独立的担当者、対応目途、重要度和ウォッチャー设置，然后点“转写内部コールセンター票”。
3. 会尝试选择“問合せ”跟踪器，题名采用 `【コールセンタ】原题名（外部：#票号）`，说明使用外部票说明，相关外部链接使用读取到的链接。対応目途使用开始日的次日；外部优先度会映射到内部优先度（不匹配末尾的“＋/－”时会尝试基础名称）。担当者会自动加入ウォッチャー。
4. 如有未确认的项目，请检查 Redmine 页面并手动补充后再提交。

## 外部票链接

在对应标签页的 Redmine 设置区修改外部票号时，工具会自动更新链接末尾 `/issues/编号`。链接的域名和前缀可以直接在链接框中编辑；之后更改票号时，会保留当前链接前缀。コールセンター读取到的原始票链接会自动填入此处。

## Formrun 问卷标题

识别到内置 SPNET/Formrun 模板后，件名会自动生成为 `[formrun] 【操作方法的回答】`；如果对应答案未提取到，则用当前模板名。重新排版时也会重新生成。生成后仍可以在标题框手动修改。

## 邮件模板

齿轮 → 邮件模板配置（JSON）。可以配置多个邮件样式、正文格式与说明栏格式；表格字段使用 `key`，普通正文可用正则 `pattern` 提取。正文可组合固定文本、空行、`{{intro}}`、`{{fields}}` 和 `{{body}}`。说明栏 `descriptionFormat` 可选择是否包含 `受信時間：{{received}}`。详细格式和示例参阅本文件夹中的《邮件模板配置说明.md》；2.3 保留全部 2.1 模板能力。

## 语言切换

点击标题右侧齿轮，在“语言”中选择简体中文、日本語或 English，再保存设置。侧栏名称随界面语言切换。

## 注意事项

- Outlook 页面或 Redmine 页面结构变化时，提取和转写可能需要调整；请检查结果。
- 正文以纯文本写入 Redmine，不保留字体、颜色或内嵌图片。
- 模板和个人字段设置存储在本机浏览器扩展中。


## 2.3 更新说明（2.3.1 沿用）

### 两个标签页的 Redmine 设置分开保存

“邮件转记”和“コールセンター”各自有担当者、対応目途、重要度、ウォッチャー及外部票号/链接设置。两边分别保存和恢复。第一次升级时，会把原 2.3 的设置作为两边的初始值；之后修改其中一边，不会覆盖另一边。

### Redmine 候选值读取

此按钮用于从**当前打开的 Redmine 新建票页面**读取本项目的担当者和重要度候选项，コールセンター页还会读取优先度候选项。请先打开要起票的项目的新建票页面，再点击对应标签页中的读取按钮。读取结果只是输入建议，实际转写仍会在 Redmine 选项中按名称匹配；读错项目时，切换项目并重新读取即可。

### 多封邮件对话

提取时会尝试将 Outlook 页面中每条邮件卡片的收件时间和正文配对，按最新邮件在前、较早回复在后的顺序放进正文。默认格式为：

```text
最新邮件正文

------

受信時間：回复时间

回复正文
```

可在齿轮 → 邮件模板配置（JSON）编辑全局 `replySeparator`、`replyFormat`、`includeReplies`；也可在单个邮件模板中设置同名属性覆盖全局值。占位符 `{{received}}` 和 `{{body}}` 分别表示这封较早邮件的收件时间和正文。设置 `includeReplies: false` 可只保留最新邮件。侧栏状态会显示读取到的较早回复数量。

Outlook 若只向页面提供最新邮件正文，或把引用内容合并成一段无法辨认的文本，工具无法可靠推断每一段的时间；此时会按现有方式读取，建议检查并手动修正正文和时间。不同 Outlook 版本的页面结构可能影响逐封配对结果。



## 2.3.1 更新说明

- 扩展邮件时间识别范围，并优先在单封邮件的页面容器内配对正文和时间，降低不同 Outlook 页面结构导致的漏提取和错配。
- 尝试识别正文中的引用块/转发块，并从较新的正文中剔除引用部分后，作为较早回复附加；若嵌入回复没有可识别时间，会只保留回复正文，不输出空的受信時間行。
- 正文段落改为每个显示块保留一个换行；只有原文中的空段落/换行才形成空行，减少签名被拉开、段落出现多余空白的问题。
- 页面结构仍会影响识别；请检查转记面板中的对话正文。
